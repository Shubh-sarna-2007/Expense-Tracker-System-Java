# Expense Tracker System (Java)

A console-based Expense Tracker System built using Java and Object-Oriented Programming concepts.

## Features

* Add Expense
* View Expenses
* Delete Expense
* Search Expense
* Calculate Total Expense
* Delete/Search by:

  * Category
  * Description
  * Date
  * Amount

## Technologies Used

* Java
* ArrayList
* OOP Concepts
* IntelliJ IDEA
